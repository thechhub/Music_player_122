# Music_player_122

Dynamic Playlist - 10 sample songs with titles, artists, and categories
Music Categories - Filter by All, Pop, Rock, Hip Hop, and Electronic
Search Functionality - Real-time search by song title or artist name
Player Controls:

Play/Pause button
Previous/Next track navigation
Progress bar with click-to-seek
Volume control slider
Time display (current/duration)


Visual Feedback:

Active song highlighting in playlist
Animated album art with category initial
Smooth transitions and hover effects
Responsive design for mobile devices


Additional Features:

Auto-play next song when current ends
Loop to first song after playlist ends
Real-time filtering maintains playback
Beautiful gradient design



🎵 How to Use:

Click any song in the playlist to start playing
Use search bar to find specific songs
Click category buttons to filter by genre
Control playback with play/pause, next/previous buttons
Click progress bar to seek through the song
Adjust volume with the slider at the bottom

Note: This is a functional simulation. To use with real MP3 files, you would need to add actual file paths to the src property in the songs array and the audio element would play real audio files.+
